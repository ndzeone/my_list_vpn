TUN — VLESS / Trojan

              

                Виртуальный сетевой адаптер и DNS для режима TUN. WireGuard/AmneziaWG
                эти настройки не используют — там IP/DNS берутся из самого конфига.
                Меняйте только при конфликте с другой программой — вступает в силу
                со следующего подключения.
              

              

                
                
                
              

            


            

              
PROXY — локальный SOCKS / HTTP

              
Порты, на которых Xray поднимает локальный прокси в режиме PROXY.

              

                
                
              

              
              

                На Linux системный прокси не переключается автоматически — после подключения в режиме PROXY
                адрес SOCKS/HTTP для ручной настройки браузера появится в журнале соединения.
