Режим

        
TUN — весь трафик устройства идёт через VPN. Требуются права администратора (приложение запрашивает их автоматически при запуске).

      


      

        
Сеть TUN (VLESS / Trojan)

        

          Виртуальный сетевой адаптер и DNS для режима vless/trojan.
          WireGuard/AmneziaWG эти настройки не используют — там IP/DNS берутся
          из самого конфига. Меняйте только при конфликте с другой программой
          (антивирус, другой VPN) — вступает в силу со следующего подключения.
