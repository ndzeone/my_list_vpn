# My List VPN

Десктоп-клиент для Windows с **настоящим системным TUN-режимом**: весь
трафик компьютера идёт через сервер, а не только браузер. Поддерживает:

- **vless://** и **trojan://** ссылки (Xray-core: TCP/WS/gRPC, TLS и REALITY,
  XTLS-flow)
- **Ссылки-подписки** (http/https) — программа скачивает и раскладывает их
  на все найденные внутри vless/trojan/WireGuard-конфиги (построчно или
  одним base64-блоком, как отдают панели вроде 3x-ui/Marzban) и добавляет
  сразу все серверы одной вставкой
- **AmneziaWG** конфиги (в том числе экспортированные из приложения Amnezia
  как JSON — программа сама найдёт `[Interface]/[Peer]` внутри)
- Обычный **WireGuard** `.conf`

Оформление — чёрный фон + оранжевые акценты, большая круглая кнопка
подключения, панели серверов/настроек выезжают сбоку.

Доступ в приложение защищён **локальным аккаунтом** (email + пароль): пароль
не отправляется никуда и не хранится — он превращается в ключ, которым
шифруется список ваших серверов (AES-256-GCM). Ни хостинга, ни базы данных
нет, всё живёт на этом компьютере. Если пароль забыт — восстановить его
нельзя, только сбросить аккаунт (кнопка на экране входа), при этом
сохранённые серверы удаляются.

Права администратора (без них TUN-режим невозможен) приложение получает
**штатным Windows-способом** — через манифест, встроенный в собранный
`.exe` (`requestedExecutionLevel: requireAdministrator`). UAC-диалог
показывает сама Windows ещё до запуска процесса; если его отклонить,
процесс просто не стартует — никаких самостоятельных перезапусков через
PowerShell приложение не делает.

## Как это устроено

Написать протокол VLESS или WireGuard "с нуля" — плохая идея (это
криптография и сетевой стек уровня ядра). Поэтому приложение — это GUI-
оболочка на Electron, которая генерирует конфиги и управляет двумя
проверенными open-source движками (как это делают v2rayN / NekoRay / сама
Amnezia):

| Профиль | Движок | Как поднимается TUN |
|---|---|---|
| `vless://` / `trojan://` | [Xray-core](https://github.com/XTLS/Xray-core) + [tun2socks](https://github.com/xjasonlyu/tun2socks) + Wintun | Xray поднимает локальный SOCKS5, tun2socks поверх Wintun превращает его в системный сетевой адаптер, маршруты настраиваются через `netsh`/`route` |
| AmneziaWG / WireGuard | [AmneziaWG для Windows](https://github.com/amnezia-vpn/amneziawg-windows-client) | Официальный тоннельный сервис сам поднимает NT-адаптер и маршруты (`amneziawg.exe /installtunnelservice`) |

Xray-core/tun2socks/wintun **не входят в репозиторий** — вкладка «Движки» в
приложении качает их официальные релизы с GitHub при первом запуске (кнопка
«Установить»). AmneziaWG, наоборот, **вшит прямо в приложение**
(`resources/amneziawg/`, см. `npm run fetch-amneziawg` для обновления
версии) — отдельно ничего не скачивается и не устанавливается, в списке
программ Windows отдельного «AmneziaWG» не появляется.

## Запуск (для разработки)

Нужен только [Node.js](https://nodejs.org) (проверено на v24).

```powershell
npm install
npm start
```

Первый `npm install` скачает Electron (~200 МБ) — это нормально.

## ⚠️ Права администратора — обязательны

TUN-режим создаёт сетевой адаптер и меняет таблицу маршрутизации — Windows
требует прав администратора.

- **Собранный `.exe`** (см. «Сборка установщика» ниже) получает права
  автоматически и правильно: в `package.json` → `build.win` прописан
  `requestedExecutionLevel: "requireAdministrator"`, electron-builder
  прошивает этот манифест прямо в exe при сборке (через `rcedit`). Windows
  сама показывает UAC-запрос перед стартом процесса — это её штатный
  механизм для приложений с таким манифестом, без единой строчки кода в
  самом приложении. Раньше здесь ещё был отдельный запасной "самоперезапуск"
  через PowerShell (`Start-Process -Verb RunAs`) — он убран, т.к. дублировал
  манифест и мог всплывать неожиданным вторым UAC-окном.
- **Dev-режим** (`npm start`) запускает голый `electron.exe`, к которому
  манифест сборки не применяется, поэтому прав администратора там по
  умолчанию нет. Два варианта: запустить сам терминал (cmd/PowerShell) от
  имени администратора и уже из него выполнить `npm start`, либо один раз
  нажать кнопку **«Перезапустить от администратора»** в баннере, который
  появляется в шапке приложения — она вызывает UAC только по клику, никогда
  автоматически.

## Сборка установщика (.exe)

```powershell
npm run dist
```

Иконка (`assets/icon.ico`/`.png`) уже сгенерирована скриптом
`build/generate-icon.js` (чистый Node, без внешних библиотек — просто
запустите `npm run gen-icon`, если захотите перерисовать).
Установщик появится в `dist/`.

## Использование

1. При первом запуске — экран **«Создать локальный аккаунт»**: email +
   пароль (только на этом компьютере, без сервера). При следующих запусках
   — экран входа с тем же паролем.
2. Нажмите на карточку сервера внизу → **«+ Добавить конфиг»**. Вставьте
   ссылку `vless://...` или `trojan://...`, **или** содержимое `.conf`
   AmneziaWG/WireGuard целиком (можно и JSON-экспорт из Amnezia — программа
   вытащит конфиг автоматически), **или** ссылку-подписку (http/https) — тогда
   добавятся сразу все серверы, которые по ней найдутся. Тип определяется по
   содержимому.
3. Значок ⚙ вверху справа → **«Движки»** → для VLESS/Trojan установите
   Xray-core (разовая загрузка ~30–50 МБ). AmneziaWG уже встроен в
   приложение, устанавливать его не нужно.
4. Выберите сервер (карточка внизу) → нажмите большую кнопку питания.
   Журнал соединения (разворачивается под карточкой) показывает, что
   происходит на каждом шаге — полезно для диагностики.

Один профиль подключён — остальные заблокированы для подключения, пока
активный не отключён (как и должно быть для системного TUN).

## Структура проекта

```
main.js                  Electron main-процесс, IPC, трей, elevation-проверка
preload.js                 Безопасный мост IPC для рендерера (contextBridge)
renderer/                  UI (чистые HTML/CSS/JS, без сборщика)
src/parsers/                 vless.js, trojan.js, wireguard.js — разбор ссылок/конфигов
                                xrayStream.js — общая часть vless/trojan (streamSettings)
src/core/
  paths.js                    все пути userData/движков, путь к вшитому AmneziaWG
  coreManager.js               скачивание Xray/tun2socks/wintun
  subscription.js               загрузка и разбор ссылок-подписок (много ключей разом)
  elevation.js                  проверка и перезапуск с правами администратора
src/engine/
  xrayEngine.js                процессы xray.exe + tun2socks.exe (vless и trojan)
  wgEngine.js                   amneziawg.exe /installtunnelservice (вшит в приложение)
  routeHelper.js                 netsh/route для TUN-адаптера (только VLESS/Trojan)
  tunController.js                оркестратор: выбор движка, состояние
  pingHelper.js                    лёгкий TCP-пинг сервера для карточки
resources/amneziawg/       amneziawg.exe + wintun.dll, вшиты в установщик (build.extraResources)
build/fetch-amneziawg.js    обновляет resources/amneziawg/ из нового релиза (npm run fetch-amneziawg)
src/store/
  profileStore.js               серверы, зашифрованные ключом аккаунта
  accountStore.js                 локальный аккаунт (email/пароль → ключ)
build/generate-icon.js       генератор assets/icon.png + icon.ico
```

## Известные ограничения / что доработать при желании

- IPv6 не обрабатывается отдельно (только `AllowedIPs`/маршруты для IPv4);
  для чистого IPv4-VPN этого достаточно.
- Для vless-профиля обходной маршрут к серверу считается один раз при
  подключении: если DNS-адрес сервера меняет IP на лету, потребуется
  переподключение.
- Один активный туннель одновременно (сознательное упрощение, как у
  большинства клиентов).
