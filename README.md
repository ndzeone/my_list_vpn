# My List VPN

My List VPN — это простой и удобный VPN-клиент, созданный для пользователей, которые хотят быстро настроить безопасное подключение без сложных настроек.

## Возможности

- 🔑 Подключение к VPN с помощью готового ключа или конфигурации
- 🌐 Туннелирование выбранных программ и сайтов через VPN
- ⚡ Возможность использовать VPN только там, где это необходимо
- 🖥️ Остальной интернет продолжает работать через ваш оригинальный IP-адрес
- 👶 Максимально простой интерфейс для новичков

## Безопасность

Ваши VPN-ключи принадлежат только вам.

- 🔒 Ключи не сохраняются на наших серверах
- 💾 Все конфигурации хранятся только локально на вашем устройстве
- 🚫 Никто, кроме вас, не имеет доступа к вашим ключам
- 🛡️ Приложение не требует отправки ваших конфигураций в облако

My List VPN создан для простого, безопасного и удобного использования VPN без лишних сложностей.
